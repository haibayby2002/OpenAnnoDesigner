# OpenAnnoDesigner

![OpenAnnoDesigner screenshot](docs/screenshot.png)

OpenAnnoDesigner is a React app (Create React App) for designing/previewing annotation layouts.

## Requirements

- **Node.js**: 18+ (recommended 20+)
- **npm**: comes with Node
- **(Optional) Docker Desktop**: for running without installing Node locally

## Install and run (local)

```bash
npm install
npm start
```

Then open `http://localhost:3000`.

### Production build (local)

```bash
npm run build
```

The static build output is in `build/`.

## Install and run (Docker)

Build and run:

```bash
docker build -t openannodesigner .
docker run --rm -p 3000:80 openannodesigner
```

Then open `http://localhost:3000`.

## Troubleshooting

- **Port already in use (3000)**: stop the other process or run Docker with a different host port:

```bash
docker run --rm -p 3001:80 openannodesigner
```

- **Windows + Docker**: make sure Docker Desktop is running and WSL2 integration is enabled.
